# bst: Create — 多层声音设计生成器

> **对标**: `nvk_CREATE`
> **定位**: 游戏音效多层资产快速探索、瞬态对齐合成与变奏生成工具

---

## 1. 核心概述

在游戏音效设计（击打、技能、爆炸、机械等）中，高品质音效通常由多个分层（Attack 起音、Body 核心、Sub 低频、Tail 尾音）叠加而成。`bst Create` 允许声音设计师通过关键词直接检索本地音效库或工程媒体，在独立的分层子轨道上随机抽取匹配样本，并利用 RMS 峰值检测将所有层的瞬态起音精准吸附重合，一键批量铺陈多组高质量变奏。

---

## 2. 界面与功能详解

### 2.1 全局搜索与素材库配置
- **全局关键词 (Global Query)**: 支持空格分割多词（如 `impact metal`）以及负号排除词（如 `-tail`）。
- **素材库设置 (Drawer)**:
  - 可指定本地音效文件夹路径（支持多路径，分号或换行分隔）。
  - 支持勾选「同时包含当前工程媒体目录」，即使未指定外置音效库也能从当前工程资产中提取组合。
  - 点击「立即扫描素材库」会在后台极速递归索引音频样本，并缓存结果。

### 2.2 多层结构设计器 (Layers)
预置 4 层结构（可分别独立启用/禁用与细调）：
- **Layer 1 [Attack]**: 专供击打瞬态、点击声（默认词：`click hit attack`）。
- **Layer 2 [Body]**: 专供材质与冲击本体（默认词：`metal punch body`）。
- **Layer 3 [Sub]**: 专供超低频能量与下潜（默认词：`sub low boom thud`）。
- **Layer 4 [Tail]**: 专供空间尾音与残响（默认词：`tail reverb ring`）。

**每层微调参数**：
- **独立搜索词**: 若留空则默认继承顶部的全局关键词。
- **±st (音高抖动)**: 为该层素材施加随机音高偏移（保持算法开启，不改变播放速率）。
- **dB (音量偏移)**: 为该层设定固定增益偏置。
- **rev% (反转概率)**: 概率性反向播放该层（极其适合 Tail / Body 产生独特冲击质感）。

### 2.3 生成与排列参数
- **变奏组数 (Variations)**: 一次性生成的变奏组合数量（1~10 组）。
- **最长秒数 (Max s)**: 限制单次事件长度，超长素材自动裁剪并平滑淡出。
- **瞬态峰值吸附对齐 (Auto Transient Align)**: 自动检测各分层音频的起音 RMS 峰值，将 Snap Offset 设在该点并横向对齐到时间线上，确保打击瞬间能量完全聚焦。
- **微淡入淡出 (Auto Fade)**: 自动施加 3ms 防爆音微淡入与尾部平滑衰减。

---

## 3. 核心工作流

1. 打开面板，输入如 `magic blast` 或 `sword slash`。
2. 调整所需变奏组数（如 3 组）。
3. 点击 **「一键生成变奏 (Generate)」**：
   - 自动在光标处生成 `[Create] 关键词` 父级折叠轨及各层子轨。
   - 沿时间线顺序铺设 3 组各不相同的随机多层组合。
4. **就地换选 (Re-roll)**：如果某一层素材不满意，直接选中该 Item，点击面板上的 **「🎲 选中项就地换选」**，即从匹配库中重新摇号换新，保留原始对齐与轨道设置。
