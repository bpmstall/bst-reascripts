# bst: Create — 多层声音设计生成器

> **对标**: `nvk_CREATE`  
> **定位**: 游戏音效多层资产快速探索、瞬态起音对齐合成与批量变奏工作台

## 1. 核心概述

在游戏音效设计（击打、技能、爆炸、机械等）中，高品质音效通常由多个分层（Attack 起音、Body 核心、Sub 低频、Tail 尾音）叠加而成。`bst Create` 允许声音设计师通过关键词直接检索本地音效库或工程媒体，在独立的分层子轨道上随机抽取匹配样本，并利用 RMS 峰值检测将所有层的瞬态起音精准吸附重合，一键批量铺陈多组高质量变奏。

---

## 2. 参数与控件说明

### 2.1 搜索与素材库
- **Query**: 检索关键词。支持空格分割多词（如 `impact metal`）以及负号排除词（如 `-tail`）。
- **Library**: 展开素材库设置面板。
  - **Library directories**: 自定义本地音效文件夹路径（支持多路径，分号或换行分隔）。
  - **Include current project media directory**: 同时索引当前工程媒体目录。
  - **Scan library**: 立即在后台极速递归索引音频样本并持久化缓存。

### 2.2 变奏与生成控制
- **Variations**: 一次性生成的变奏组合数量（1~10 组）。
- **Max length (s)**: 限制单次事件长度，超长素材自动裁剪并平滑淡出。
- **Snap to transient peak**: 自动分析各层音频起音 RMS 峰值，将 Snap Offset 设在该点并横向对齐到时间线上，确保打击瞬间能量完全聚焦。
- **Auto fade**: 自动施加 3ms 防爆音微淡入与尾部平滑衰减。

### 2.3 分层配置 (Layers)
预置 4 层结构（可分别独立启用/禁用与细调）：
- **L1 [Attack]**: 专供击打瞬态、点击声（默认词：`click hit attack`）。
- **L2 [Body]**: 专供材质与冲击本体（默认词：`metal punch body`）。
- **L3 [Sub]**: 专供超低频能量与下潜（默认词：`sub low boom thud`）。
- **L4 [Tail]**: 专供空间尾音与残响（默认词：`tail reverb ring`）。

每层支持微调：
- **独立搜索词**: 若留空则默认继承顶部的通用 Query。
- **±st**: 为该层施加随机音高偏移（自动开启保留音高算法）。
- **dB**: 为该层设定固定增益偏置。
- **rev%**: 概率性反向播放该层（适合 Tail / Body 产生独特冲击质感）。

---

## 3. 操作按钮

- **Generate variations**: 一键在光标处生成 `[Create] 关键词` 父级折叠轨及各层子轨，沿时间线整齐铺设 N 组各不相同的随机多层组合。
- **Re-roll selected**: 选中时间线上任意 Item，一键按原本词库重新换选一个随机样本，保留原始轨道与对齐关系。
