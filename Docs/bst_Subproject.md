# bst: Subproject — 子工程工作流助手

> **对标**: `nvk_SUBPROJECT`
> **定位**: 复杂分层音效打包隔离、边界标记自动化校准与代理渲染

---

## 1. 核心概述

现代游戏音频项目中，单个音效动辄包含数十轨素材、包络与效果器链。若全部散落在主工程中，会导致工程卡顿、视线混乱且难于协同。`bst Subproject` 实现了主工程与子工程（Subproject / `.rpp`）之间的极速打包、无损迁移、边界自动标定与静默代理更新。

---

## 2. 界面与功能详解

### 2.1 状态感应
- **主工程模式**: 面板显示打包操作，可选择将「选中的轨道/文件夹」或「选中的 Items 所在轨道」一键打包为独立的子工程。
- **子工程模式**: 当用户双击打开某个子工程标签页时，面板自动识别为子工程环境，提供一键对齐标记与代理渲染。

### 2.2 渲染边界自动标定 (=START / =END)
REAPER 渲染 Subproject 时依据 `=START` 和 `=END` 标记判定范围。音效师经常在修改子工程后由于尾音变化导致代理被截断或留白过长。
- **一键校准标记**: 脚本精准扫描子工程中所有**未静音**的 Items 边界。
- **前置余量 (Head s)**: 给音效起始留出安全缓冲（默认 0s）。
- **尾音余量 (Tail s)**: 为残响/延迟尾音留出缓冲（默认 0.5s，可调至 5.0s）。
- **自动渲染代理**: 校准后自动静默触发 `.rpp-prox` 渲染并保存，主工程瞬时同步。

---

## 3. 核心工作流

1. **打包**: 在主工程制作好一组分层（如 `bst Create` 产生的文件夹），选中该 Folder 轨，点击 **「📦 将选中轨道打包为子工程」**。
2. **轻量化**: 主工程原位替换为一个渲染好的轻量代理条目。
3. **深入修改**: 双击代理条目进入子工程标签页，调整插件参数或素材。
4. **一键同步**: 点击 **「🎯 一键校准 =START / =END 标记」**，标记自动更新并保存渲染，切回主工程立刻听到最终更新结果。
