# bst: Search Palette — 全局命令与资产面板

> **对标**: `nvk_SEARCH`
> **定位**: 键盘流极速调用轨道、素材、标记、插件与自定义脚本

---

## 1. 核心概述

全键盘交互式命令浮动面板（按 ESC 退出，上下键选择，回车执行）。通过统一入口直接搜索整个 REAPER 工程或系统扩展。

---

## 2. 范围前缀搜索语法

输入前缀 + 空格，即可锁定检索范围：
- `t 关键词`: 检索工程轨道 (Tracks)
- `i 关键词`: 检索工程素材 (Items)
- `m 关键词`: 检索标记与区域 (Markers / Regions)
- `f 关键词`: 检索效果器插件 (FX)，回车直接插入到选中轨道
- `s 关键词`: 检索 Action List 与自定义脚本 (Scripts)
- 直接输入词组：跨全范围联合检索。
