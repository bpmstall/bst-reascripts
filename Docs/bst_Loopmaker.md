# bst: Loopmaker — 无缝循环生成器

> **对标**: `nvk_LOOPMAKER`
> **定位**: 基于零交叉对齐与头尾交叉淡化，批量生产无缝环境/机械音频循环

---

## 1. 核心概述

为游戏制作风声、引擎声、环境氛围声（Ambience）时，循环制作极其耗时。`bst Loopmaker` 针对选中的长音频素材，截取内容窗口并自动在零交叉点（Zero Crossing）寻找最佳对齐缝合点，施加头尾反向交叉淡化后离线渲染为无缝 WAV，并在工程中重新载入且默认开启 `Loop Source`。

---

## 2. 功能详解

- **循环变奏数 (Count)**: 单个素材一次性产出的变奏循环条目数量。
- **交叉淡化时长 (xf_ms)**: 头尾缝合淡化窗口（通常 50~200ms）。
- **内容随机平移 (Shuffle)**: 每个生成的变奏从源素材不同时间区间采样，避免循环单一。
- **输出目录**: 统一保存在 `<工程媒体目录>/bst_loops/`，规范整洁。
